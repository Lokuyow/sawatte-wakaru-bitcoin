₿ さわってわかるビットコイン

ぜんぶシミュレーションやで。本物のビットコインは1円も動かへんし、ネットにもつながらへん。

1. ハッシュ = データの指紋

SHA-256は、どんな文章でも64文字の「指紋」に変える計算や。1文字変えるだけで指紋はまるっきり別モンになるで。

2. ブロックとチェーン

各ブロックは「ひとつ前のブロックのハッシュ」を持ってる。昔のデータを書きかえると、それ以降のつながりが全部こわれるんや。

3. マイニング

ハッシュが「0」をN個並べて始まるナンスをひたすら探すゲームや。0を1個増やすと、平均でだいたい16倍たいへんになるで。

—

ナンス: 0 / 試した回数: 0

本物のビットコインは0がもっといっぱい要るし、世界中のマシンが競争してるで(ここは雰囲気だけ)。

4. 秘密鍵・公開鍵・署名

秘密鍵を持ってる人だけが署名できて、公開鍵があれば誰でも「本人のや」って確認できる。メッセージを1文字でもいじると確認は失敗するで。

※ブラウザの中で使い捨ての鍵をその場で作る練習用デモ(ECDSA P-256)。ビットコイン本体はsecp256k1という別の曲線を使う。あなたの鍵は絶対入力せんといてな。

5. 取引とみんなの台帳

取引はみんなが同じ台帳でチェックする。持ってない分のコインや、もう使ったコインを使おうとすると(二重払い)はじかれるんや。
